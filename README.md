# Etherscan API App

A React.js dashboard for exploring Ethereum wallet data using the Etherscan API.

## Features

- **Wallet Balance** – Enter any Ethereum address to instantly fetch its ETH balance
- **Transaction History** – Browse a full list of past transactions for any wallet
- **Token Holdings** – View all ERC-20 tokens held by a given address

## Tech Stack

- **React.js** – Frontend UI
- **Etherscan API** – Blockchain data source

## Getting Started

### Prerequisites

- Node.js installed
- A free Etherscan API key from [etherscan.io](https://etherscan.io/apis)

### Installation

```bash
git clone https://github.com/RajatSinghhh/Etherscan-api-app
cd Etherscan-api-app
npm install
```

### Configuration

Create a `.env` file in the root directory and add your API key:

```env
REACT_APP_ETHERSCAN_API_KEY=your_api_key_here
```

### Run the App

```bash
npm start
```

The app will start at `http://localhost:3000`.
